# 芯位网课辅助 · 用户指南

> 芯位（beeline-ai.com）课程挂机 + AI 答题助手。MIT 开源，单机自填 Key，不上报任何数据。
> 本指南面向使用者；开发/架构见 [README](../README.md) 与 [frontend-map](frontend-map.md)。

## 1. 安装

1. 浏览器安装 [ScriptCat（脚本猫）](https://scriptcat.org/) 扩展（也兼容 Tampermonkey）。
2. 打开 `dist/xinwei-autostudy.user.js` 的原始文件内容，在脚本猫「编辑脚本」中粘贴保存（或拖入安装）。
3. 登录芯位学习中心（`www.beeline-ai.com/student`），页面左上角出现悬浮面板即安装成功。

## 2. 面板速览

| 区域 | 控件 | 说明 |
|---|---|---|
| ⚙ 挂机 | 全自动刷课 | 主开关：自动播视频/翻章节/静音挂后台；下方显示课程进度与剩余视频时长估算 |
| ⚙ 挂机 | 静音按钮 | 整页静音三重拦截，点击可恢复声音 |
| 🤖 答题 | 接口配置 | 填大模型 API Key + Base + 模型名（默认 DeepSeek，兼容 OpenAI 协议接口） |

## 3. 答题确认模式（v3.13.0 新增）

开启「答题确认」后，脚本行为变为**半自动**：

- AI 仍然自动答题、自动回填选项/填空/主观题；
- 填完**立即暂停**：不自动翻下一题、不自动提交；
- 你在页面上核对答案，自行点击「下一题」，最后一题自行点「提交作业」；
- 自动提交开关在此模式下整体停用。

适合：想保留人工把关、怕 AI 答错直接交卷的场合。视频内弹题同样只填不交。

## 4. 视频内弹题（v3.13.0 新增）

视频播到出题点会暂停并弹窗。开启自动答题后，脚本会：

1. 识别弹窗题目（单选/多选/判断），走同一套 AI 引擎作答；
2. 自动勾选选项并点「提交」，提交后自动关闭弹窗，视频继续播放；
3. AI 失败或「答题确认」开启时停在弹窗等你处理；已答过的弹窗直接关闭续播。

## 5. 常见问题

**Q：AI 一直没反应？**
检查 Key/模型名。模型名错误会触发熔断并在日志显示 `⛔`，改正配置项后自动恢复。用「🩺 诊断」看页面题目能否解析。

**Q：视频卡住不动？**
脚本有看门狗：45s 无进度自动重点播，120s 无进度自动刷新页面，一般无需干预。若反复刷新，看日志里的平台提示文案。

**Q：章节是灰色的点不进去？**
章节有开放时间窗（未到/已过期），脚本会自动跳过锁定章；全部可见节刷完后进入「守望模式」等解锁，到期自动刷新续刷。

**Q：会封号吗？**
平台服务端可见观看行为，进度异常（清进度）风险始终存在。请自行控制使用强度，避免全天候连挂、一次刷完整个学期。

**Q：答案对不对？**
AI 不保证正确率，多选/主观题尤甚。重要的课建议开「答题确认」人工过一遍，或交卷后用复盘页核对。

## 6. 隐私与安全

- API Key 只存在你本机（GM 存储），请求只发往你配置的接口地址；
- 开启检索增强会把题目文本发给 DuckDuckGo/Tavily，涉及隐私题目请保持关闭；
- 脚本无任何数据上报，代码公开可审计。
