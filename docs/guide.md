# 芯位网课辅助 · 用户指南

> 芯位（beeline-ai.com）课程挂机 + AI 答题助手。MIT 开源，单机自填 Key，不上报任何数据。
> 本指南面向使用者；开发/架构见 [README](../README.md) 与 [frontend-map](frontend-map.md)。

## 1. 安装

1. 浏览器安装 [ScriptCat（脚本猫）](https://scriptcat.org/) 扩展（也兼容 Tampermonkey）。
2. 打开 `dist/xinwei-autostudy.user.js` 的原始文件内容，在脚本猫「编辑脚本」中粘贴保存（或拖入安装）。
3. 登录芯位学习中心（`www.beeline-ai.com/student`），页面左上角出现悬浮面板即安装成功。

## 2. 面板速览

| 区域 | 控件 | 说明 |
|---|---|---|
|  挂机 | 全自动刷课 | 主开关：自动播视频/翻章节/静音挂后台；下方显示课程进度与剩余视频时长估算 |
|  挂机 | 截止提醒 | 每 30 分钟自动检查全部在学课程的未完成作业，截止前 3 天在面板横幅提醒（不足 24 小时标红）；「 检查作业截止」按钮可立即检查 |
|  挂机 | 静音按钮 | 整页静音三重拦截，点击可恢复声音 |
|  挂机 | 智能倍速 | 自动识别平台倍速菜单（0.5x-2x），有菜单的视频自动点最高档；无菜单的视频不碰；触发「不允许倍速播放」后 30 分钟内不再尝试 |
|  答题 | 接口配置 | 填大模型 API Key + Base + 模型名（默认 DeepSeek，兼容 OpenAI 协议接口） |
|  答题 | 检索增强 | 事实/时事类题目先联网搜索再作答；默认关闭（会把题目发给外部搜索引擎） |
|  答题 | 自动答题 | 每 3s 扫描卷面页，抓到题目自动作答并跳下一题；含作业列表巡航 |
|  答题 | 提交方式 | 三选一：人工核对提交（默认）/ 答完自动提交（高风险项）/ 填完暂停待确认（见下）；旧版「答完自动提交/答题确认」两开关自动迁移 |
|  答题 | 答题间隔 | 每答完一题等待 N 秒再答下一题（模拟人工节奏，默认 0） |

## 3. 提交方式（三选一）

面板「提交方式」下拉控制 AI 答完之后交不交卷：

- **人工核对提交**（默认）：AI 答完自动翻下一题，最后由你手动点「提交作业」；
- **答完自动提交**：全卷答完后自动点「提交作业」并确认；平台提示有未答题时自动取消提交，留给人工补答。影响真实成绩，属高风险项；
- **填完暂停待确认**（原「答题确认」）：AI 仍然自动答题、自动回填，但填完**立即暂停**——不自动翻题、不自动提交，你在页面上核对后自行点「下一题」，最后一题自行点「提交作业」。视频内弹题同样只填不交。

适合想保留人工把关、怕 AI 答错直接交卷的场合选「填完暂停待确认」。旧版「答完自动提交/答题确认」两个开关的配置升级后自动迁移（当时确认模式开着 → 迁移为「填完暂停待确认」）。

## 4. 视频内弹题（v3.13.0 新增）

视频播到出题点会暂停并弹窗。开启自动答题后，脚本会：

1. 识别弹窗题目（单选/多选/判断），走同一套 AI 引擎作答；
2. 自动勾选选项并点「提交」，提交后自动关闭弹窗，视频继续播放；
3. AI 失败或提交方式选「填完暂停待确认」时停在弹窗等你处理；已答过的弹窗直接关闭续播。

## 5. 作业截止提醒（v3.14.0 新增）

脚本每 30 分钟（跨页面刷新共享节流）自动拉取全部**在学课程**的未完成作业列表：

- 距截止 **3 天内**：挂机页出现橙色横幅，逐条列出「课程 · 作业名 · 截止时间」；
- 距截止 **不足 24 小时**：横幅变红并标注「不足 24 小时！」，日志同步提示；
- 已过期的作业不再提醒（一般也无法提交了）；待批改/已完成的作业不提醒；
- 结果会缓存，刷新页面后横幅立即显示，不用等下一次检查；
- 也可以随时点挂机页「 检查作业截止」手动拉取一次。

提醒只是提示，不会自动打开或作答那份作业——是否赶、怎么做由你决定。

## 6. 代码题自动运行验证

遇到「程序输出什么 / 补全代码 / 复杂计算」类题目时，AI 可以**先在本机沙箱里实际运行代码验证**，再给最终答案：

- AI 会把非 JavaScript 代码（Python 等）翻译成等价 JS，在脚本创建的 Worker 沙箱里运行，把日志和结果拿回去迭代分析（最多运行 3 次）；
- 沙箱是纯计算环境：无 DOM、无网络（fetch/XHR/WebSocket 会被拦截并提示 AI 改用纯计算）；单次运行 5 秒超时自动终止死循环；
- 面板日志会显示  沙箱运行过程与结果，可据此核对 AI 的推理；
- 沙箱执行的是 AI 生成的代码——封锁为软性检查，理论上可被刻意构造绕过；代码来源是你自己配置的大模型服务，请自行评估信任度。

## 7. 常见问题

**Q：AI 一直没反应？**
检查 Key/模型名。模型名错误会触发熔断并在日志显示 ``，改正配置项后自动恢复。用「 诊断」看页面题目能否解析。

**Q：视频卡住不动？**
脚本有看门狗：45s 无进度自动重点播，120s 无进度自动刷新页面，一般无需干预。若反复刷新，看日志里的平台提示文案。

**Q：章节是灰色的点不进去？**
章节有开放时间窗（未到/已过期），脚本会自动跳过锁定章；全部可见节刷完后进入「守望模式」等解锁，到期自动刷新续刷。

**Q：会封号吗？**
平台服务端可见观看行为，进度异常（清进度）风险始终存在。请自行控制使用强度，避免全天候连挂、一次刷完整个学期。

**Q：答案对不对？**
AI 不保证正确率，多选/主观题尤甚。重要的课建议提交方式选「填完暂停待确认」人工过一遍，或交卷后用复盘页核对。

## 8. 隐私与安全

- API Key 只存在你本机（GM 存储），请求只发往你配置的接口地址；
- **密钥自动加密**：保存 Key 后即以本机设备密钥自动加密落盘（AES-GCM-256），本地存储不再有明文，刷新/重启自动解锁，全程无感。防护边界：防存储被随手翻看、明文被一眼复制；
- **口令加固（可选）**：在  答题页填写口令后点「 加密保存」，改为口令加密——密文连同整份浏览器配置被拷走也无法解开，浏览器重启后需输口令解锁（同一标签会话内自动）。适合公用电脑/担心配置被同步泄露的场景；
- 开启检索增强会把题目文本发往检索源（Bing 国内直连，唯一检索源），涉及隐私题目请保持关闭；
- 脚本无任何数据上报，代码公开可审计。
