# 芯位网课辅助 · Xinwei AutoStudy

基于大语言模型（LLM）的 [beeline-ai.com](https://www.beeline-ai.com)（芯位）网课学习辅助**用户脚本**（UserScript）。
以 **MIT 协议**开源，源码与构建流程完全公开。

>  本脚本仅供**计算机自动化技术交流与学习**。请在遵守平台规则与当地法律的前提下使用；
> AI 不保证 100% 正确率，刷完课建议自行复习。使用风险请自行承担。

> 超星学习通（chaoxing.com）支持已拆分至独立项目 `chaoxing-autostudy`，两者共享 AI 答题内核，平台逻辑各自独立维护。

---

## 功能

- **自动刷课**：自动播放、防挂机检测规避（伪造可见/聚焦状态 + 合成随机交互）、PPT/静态课件停留即过（等待 iframe 就绪防白页空跳）、章节完成判定与自动跳转（侧边栏目录穿透找下一节）。**整页静音**：媒体元素挂载即静音、播放前强制静音、页面取消静音即时压回（三重拦截），面板可一键恢复声音。**弹题/答题浮层避让**：浮层出现时不催播、不合成点击，避免与平台答题机制互踩。
- **跳转可靠性**（v3.9.0）：视频卡死看门狗（无进度 → 重点播 → 自动刷新，阶梯自愈）；完成判定按平台「观看 95% 计完成」规则取 96% 阈值（同时覆盖流尾部挂起）；媒体事件驱动（放完即跳，后台标签页节流也不延迟）；跳转落地校验（点击未生效将可见重试）；**章节解锁守望**（剩余章均未到开放时间时不再误报「挂机完成」，记录解锁时间自动复查续刷）；面板实时显示当前节与观看百分比。
- **AI 答题**：支持单选 / 多选 / 判断 / 填空 / 主观题。主观题按题目分值自适应篇幅（30 分大题约 600 字）；客观题解析失败自动强调格式重试一次。
- **视觉模型答图片题**（选配）：题干/选项带图（几何图、图表、公式截图）时，若配置了视觉模型（如 Qwen2.5-VL、GLM-4V），自动拉取图片转 dataURL 走该模型看图作答；未配置时维持纯文本作答。视觉模型与主模型共用同一端点与 Key，仅模型名不同。
- **答题间隔**（默认 0）：可设定每题答完后的等待秒数再答下一题，让答题节奏更接近人工。
- **答题模式**（v3.12.0 起）：做题完全交给 AI 现场作答——不再维护任何答案缓存/回放；AI 未答出的题重试并留人工。
- **检索增强（RAG）**（默认关闭）：对事实/时事类题目，答题前先通过 Bing（国内直连，无需密钥）检索资料，提升准确率。检索会向外部引擎发送题目内容，属风险项，支持 `off / auto / always` 三档由用户显式开启。
- **代码题本机沙箱执行**：判定为代码/程序类题目时，LLM 可要求在本机 Worker 沙箱实际运行 JavaScript（Python 等先翻译成等价 JS）验证推理——运行日志与结果回灌模型迭代（≤3 轮）后再作答。沙箱独立线程 5s 超时杀死死循环；网络 API（fetch/XHR/WebSocket）静态拦截，纯计算环境（软性封锁，对抗构造可绕过，代码来源为用户自配的 LLM）。
- **图片作答题自动跳过**：题干要求上传图片 / 拍照作答的题目不调用 AI，记录跳过并在日志提示人工处理；作业巡航重进同一份作业时直接跳过。
- **作业巡航**：开启自动答题后，自动打开作业列表逐份完成（列表 → 做作业 → 答题 → 提交 → 下一份）；也可点面板「 巡航」从课程页一键进入。
- **答完自动提交**（默认关闭）：精确匹配「提交作业」按钮并自动确认；平台提示有未答题时自动取消，留给人工补答。影响真实成绩，属高风险项。
- **答题确认模式**（v3.13.0，默认关闭）：开启后 AI 填完答案即暂停——不自动翻题、不自动提交，人工核对后自行操作；自动提交在该模式下整体停用。
- **视频内弹题自动作答**（v3.13.0）：视频播到出题点暂停弹窗时，走同一 AI 引擎识别并作答（单选/多选/判断），自动提交并关闭弹窗续播；AI 失败或确认模式下留人工处理。
- **作业截止提醒**（v3.14.0）：每 30 分钟自动检查全部在学课程的未完成作业（接口直拉，30 分钟跨刷新节流），截止前 3 天在面板横幅提醒、不足 24 小时升级红色；已过期/已完成不提醒，结果缓存供刷新后免请求展示。
- **运行时段表**：可设定自动刷课/自动答题的执行时段（如 `23:00-07:00`，支持跨零点），时段外自动功能暂停、手动操作不受影响；时段跨越自动恢复并记录日志。
- **连接健康检查**：面板一键向当前端点发最小请求，测 API Key / 模型名 / 连通性与延迟，失败按原因归类（Key 无效 / 余额不足 / 模型名无效 / 限流）。
- **油猴菜单快捷开关**：扩展菜单内直接暂停/恢复自动答题与自动刷课、最小化/展开面板，面板被遮挡时也能控制。
- **配置熔断**：模型名 / API Key / 余额等确定性配置错误不再无限重试，明确提示并暂停，面板改正后自动恢复。
- **异常自愈**：平台弹出「学习状态异常」「不允许倍速播放」「播放位置不合法」等风控提示时自动刷新页面续跑（20s 冷却防死循环）。
- **性能**（v3.9.1）：风控弹窗检测快/慢双路径（常态零强制重排）；无题目路由（视频/课程页）跳过题目扫描；媒体监听与整页静音按批处理。
- **页面动画冻结**：全页 CSS 动画/过渡压至近零时长（保留 `animationend`/`transitionend` 事件回调，Vue 组件显隐逻辑不受影响），骨架屏微光、loading 旋转、弹窗过渡瞬时完成，降低页面合成/绘制开销。默认启用，无需配置。
- **竖屏适配**：芯位布局层无任何响应式设计（视口 ≤1199px 时被 `min-width:1200px` 硬墙限制只能横向滚动），脚本注入补丁 CSS 解锁硬墙并收敛头部/留白，竖屏平板、竖装显示器、分屏窄窗口自动生效。纯表现层，不影响自动化逻辑。
- **主观题草稿防丢**：简答/论述编辑器内容每 5 秒存本地（纯本地存储，上限 20 条、7 天过期）；页面被风控自愈刷新/崩溃/误关后重进，编辑器为空时自动恢复草稿并提示核对——AI 提交后的正常清空不会误回填。
- **作业/考试页防误关**：作业/考试路由下关闭或刷新标签页前弹浏览器原生确认，手滑不再丢作答现场；脚本自身的风控自愈刷新不受影响。
- **暗色护眼模式**：面板开关。覆盖平台浅色 CSS 变量与硬编码背景，视频/图片原样不受影响；首版覆盖面有限，漏网的刺眼区域持续补充。
- **降画质省性能**：面板开关。每个视频自动选最低画质档，大幅降解码 CPU 与带宽占用（平台本就有画质菜单，切换属正常行为不碰风控）；想看清视频时关闭即可。
- **悬浮控制面板**：双开关、AI 配置、实时进度与会话统计（已答 / 已提交）、课程进度与剩余视频时长估算、日志一键复制（v3.13.0）；面板位置与最小化状态自动记忆。屏幕自适应：窄视口宽度自动收缩、内容超高内滚、横竖旋转/缩放窗口后自动回到可见范围，平板触屏可直接拖动。

## 安装

1. 安装油猴类扩展：[Tampermonkey](https://www.tampermonkey.net/) 或 [ScriptCat](https://scriptcat.org/)。
2. 获取脚本（任选其一）：
   - 脚本猫安装页：<https://scriptcat.org/zh-CN/script-show-page/8163>；或
   - 开发版：仓库 `dist/xinwei-autostudy.user.js`，直接拖入扩展安装；或
   - 自行构建（见下）。
3. 打开 `beeline-ai.com` 任意课程页，左上角出现控制面板即生效。

面板各开关的含义、答题确认模式与常见问题见 **[用户指南](docs/guide.md)**。

## 构建（从源码）

源码按模块拆分在 `src/`，通过 `build.js` 拼接为单一用户脚本（共享同一 IIFE 作用域）。
构建时会自动剥离整行注释并折叠空行（模板字符串内容原样保留），发布版体积更小、源码保持可读。

```bash
node build.js          # 生成 dist/xinwei-autostudy.user.js
node build.js --watch  # 监听 src/ 变化自动重建（需手动刷新浏览器）
```

目录结构：

```
src/
  meta.js       用户脚本元数据头（==UserScript==）
  config.js     全局配置 CFG / 持久化键 / loadCfg
  utils.js      通用工具：可见性判定、DOM 小工具、静音、防挂机、滚动、侧边栏穿透查找、exactText
  sites.js      站点适配层（beeline 平台 DOM）：题目容器选择器、题目解析、选项/答案提取、接口题目镜像
  tools.js      本机沙箱代码执行（代码题工具）：Worker 沙箱 + 网络软封锁 + ```run 协议与结果回灌
  qa.js         AI 答题核心：状态机 / 检索 / LLM 调用与解析（含代码题工具循环）/ 回填 / 校验 / 提交 / 作业巡航
  ui.js         控制面板 UI（CSS / DOM / 拖动 / 位置记忆 / 事件绑定）
  autoplay.js   自动刷课主循环与章节跳转
  popup.js      学习状态异常弹窗自动刷新
  bootstrap.js  入口：防重复注入、加载配置、挂载 UI、启动
build.js        拼接 + 发布版瘦身 + terser 压缩（-42%，头部逐字节保留）+ 版本注入（__XA_VERSION__）
dist/           构建产物
scripts/        仓库侧工具（sync-version.js 版本一致性检查；lint-bundle.js 生成 lint 用 bundle）
eslint.config.js ESLint 扁平配置（bundle + 仓库侧 Node 文件，npm run lint）
tests/          Node 测试（harness.js 直加载 src；run-all.js 跑全部套件；npm test = 构建+测试）
.github/        CI（ci.yml：版本一致性 + 构建 + 语法 + 全量测试）
legacy/         原始脚本与补丁（仅作参考，不再维护）
```

架构约束（改代码前读）：

- 所有 `src/*.js` 共享同一 IIFE 作用域，加载顺序由 `build.js` 的 `BODY_ORDER` 决定。
- 版本号只改 `src/meta.js` 的 `@version`；`bootstrap.js` 内的 `__XA_VERSION__` 由构建注入；安装后跑 `npm run version:check` 可验证 `package.json` 同步（CI 强制）。
- 测试使用 `tests/harness.js` 从 src 直加载（vm 沙箱），不再从 dist 抠函数文本——函数签名变更会立刻显式报错。
- **发布版压缩**：`build.js` 用 terser 只压 IIFE 主体（头部逐字节保留，扩展靠它识别脚本），体积 155→91 KB（-42%）。terser 缺失时自动降级为未压缩构建；`node build.js --no-min` 可强制跳过。压缩产物的回归由 `tests/test-dist.js`（结构/字符串清单/体积闸门）与 `tests/test-startup.js`（jsdom 真实执行启动）覆盖，`node tests/run-all.js` 一并运行。
- **Lint 门禁**：`npm run lint` 用 ESLint 检查两块——src 按 `BODY_ORDER` 拼接后的未压缩 bundle（`scripts/lint-bundle.js` 生成到 `tmp/`，浏览器 + GM_* 环境；跨模块 `no-undef` 只有拼接后才可判）与仓库侧 Node 文件（build/scripts/tests）。CI 强制。之所以不逐文件 lint src：模块共享 IIFE 作用域，单文件视角跨模块符号全是误报。
- 开发依赖：`npm i`（terser 压缩必需、jsdom 启动测试必需、eslint/@eslint/js/globals lint 必需；缺失时相应环节优雅跳过并提示）。

## 配置

在控制面板「 答题」页填写：

| 项 | 说明 | 默认 |
| --- | --- | --- |
| API Key | 你自己的大模型密钥（不上报），存于脚本本地存储（与页面隔离，仅本脚本可读） | 空 |
| API Base URL | 兼容 OpenAI `/v1/chat/completions` 的端点 | `https://api.deepseek.com` |
| 模型名称 | 思考模型（`deepseek-reasoner` 等）自动放宽 token 与超时；也可用 `deepseek-chat` / `gpt-4o-mini` | `deepseek-reasoner` |
| 视觉模型 | 选填；题干带图时改走该模型看图作答（DeepSeek 系纯文本模型看不了图，需另配多模态模型，如 SiliconFlow 的 `Qwen/Qwen2.5-VL-72B-Instruct`） | 空（图片题按纯文本作答） |
| 检索模式 | `off` / `auto` / `always`（风险项，题目内容会发往外部引擎） | `off` |
| 检索源 | Bing 国内直连（已固定，无需密钥） | — |
| 答题间隔 | 每题答完后等待秒数再答下一题，0 = 不等待 | 0 |
| 运行时段 | 自动刷课/答题的执行时段 `HH:MM-HH:MM`（支持跨零点），空 = 全天 | 空 |
| 答完自动提交 | 高风险项，影响真实成绩 | 关 |

推荐白嫖：硅基流动 (SiliconFlow)、DeepSeek 官方等平台新用户通常赠送免费额度。

> 关于 `meta.js` 中的 `@connect *`：API Base URL 由用户自行配置（任意 OpenAI 兼容端点），
> 无法预先枚举全部域名，故必须开放通配；具体已知域名同时列出仅作文档参考。脚本不含任何数据上报。
