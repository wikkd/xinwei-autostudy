# 芯位网课辅助 · Xinwei AutoStudy

基于大语言模型（LLM）的网课学习辅助**用户脚本**（UserScript），支持 `beeline-ai.com`（芯位）与 `chaoxing.com`（超星学习通）双平台。
以 **MIT 协议**开源，源码与构建流程完全公开。

> ⚠️ 本脚本仅供**计算机自动化技术交流与学习**。请在遵守平台规则与当地法律的前提下使用；
> AI 不保证 100% 正确率，刷完课建议自行复习。使用风险请自行承担。

---

## 功能

- **多平台支持**：芯位 beeline-ai.com + 超星学习通 chaoxing.com（v2.1+，站点适配层自动识别）。
- **自动刷课**：自动播放、防挂机检测规避（伪造可见/聚焦状态 + 合成随机交互）、PPT/静态课件停留即过、章节完成判定与自动跳转。
  - 超星：穿透同源 iframe 驱动视频播放（点「播放视频」大按钮、静音、合成鼠标移动防失焦暂停），播完 ≥92% 自动点「下一节」。
- **AI 答题**：支持单选 / 多选 / 判断 / 填空 / 主观题。主观题按题目分值自适应篇幅（30 分大题约 600 字）；客观题解析失败自动强调格式重试一次。
- **答案本**：回填成功的题目自动缓存到本地（题干 + 选项哈希 → 答案），重做 / 重进同一份试卷直接回填，不再重复调用 AI，省时省额度。
- **检索增强（RAG）**：对事实/时事类题目，答题前先通过 DuckDuckGo（免密钥）或 Tavily（需 Key）检索资料，提升准确率。支持 `off / auto / always` 三档。
- **作业巡航**：开启自动答题后，自动打开作业列表逐份完成（列表 → 做作业 → 答题 → 提交 → 下一份）；也可点面板「🧭 巡航」从课程页一键进入。
- **答完自动提交**：精确匹配「提交作业」按钮并自动确认；平台提示有未答题时自动取消，留给人工补答。
- **配置熔断**：模型名 / API Key / 余额等确定性配置错误不再无限重试，明确提示并暂停，面板改正后自动恢复。
- **异常自愈**：平台弹出「学习状态异常」时自动刷新页面续跑。
- **悬浮控制面板**：双开关、AI 配置、实时进度与会话统计（已答 / 缓存命中 / 已提交）、可拖拽调整的日志窗口；面板位置与最小化状态自动记忆。

## 安装

1. 安装油猴类扩展：[Tampermonkey](https://www.tampermonkey.net/) 或 [ScriptCat](https://scriptcat.org/)。
2. 获取脚本：
   - 开发版：仓库 `dist/xinwei-autostudy.user.js`，直接拖入扩展安装；或
   - 自行构建（见下）。
3. 打开 `beeline-ai.com` 或 `i.chaoxing.com`（超星学生端）任意课程页，左上角出现控制面板即生效。

一键部署（开发辅助）：`node deploy.js` 会自动构建 → 复制剪贴板 → 定位 ScriptCat 编辑器标签 → 粘贴保存（需 Chrome 已打开编辑器标签）。

## 构建（从源码）

源码按模块拆分在 `src/`，通过 `build.js` 拼接为单一用户脚本（共享同一 IIFE 作用域）。
构建时会自动剥离整行注释并折叠空行（模板字符串内容原样保留），发布版体积更小、源码保持可读。

```bash
node build.js          # 生成 dist/xinwei-autostudy.user.js
node build.js --watch  # 监听 src/ 变化自动重建（需手动刷新浏览器）
```

目录结构：

```
src/
  meta.js       用户脚本元数据头（==UserScript==）
  config.js     全局配置 CFG / 持久化键 / loadCfg
  utils.js      可见性判定、DOM 小工具、静音、防挂机、滚动、侧边栏穿透查找
  sites.js      多站点适配层：XA_SITE 识别 + 超星 CX（视频穿透/章节跳转）+ 超星题库适配器 CXQA
  qa.js         AI 答题核心：抓取 / 检索 / 调用 LLM / 回填 / 校验 / 提交 / 巡航 / 答案本
  ui.js         控制面板 UI（CSS / DOM / 拖动 / 位置记忆 / 事件绑定）
  autoplay.js   自动刷课主循环与章节跳转
  popup.js      学习状态异常弹窗自动刷新
  bootstrap.js  入口：防重复注入、加载配置、挂载 UI、启动
build.js        拼接 + 发布版瘦身
deploy.js       一键部署到浏览器 ScriptCat（构建→剪贴板→编辑器粘贴保存）
dist/           构建产物
legacy/         原始脚本与补丁（仅作参考，不再维护）
```

## 配置

在控制面板「🤖 答题」页填写：

| 项 | 说明 | 默认 |
| --- | --- | --- |
| API Key | 你自己的大模型密钥（不上报） | 空 |
| API Base URL | 兼容 OpenAI `/v1/chat/completions` 的端点 | `https://api.deepseek.com` |
| 模型名称 | 如 `deepseek-chat` / `deepseek-flash` / `gpt-4o-mini` | `deepseek-chat` |
| 检索模式 | `off` / `auto` / `always` | `auto` |
| 检索源 | `duckduckgo`（免密钥）/ `tavily`（需 Key） | `duckduckgo` |
| Tavily Key | 仅 Tavily 模式需要 | 空 |

推荐白嫖：硅基流动 (SiliconFlow)、DeepSeek 官方等平台新用户通常赠送免费额度。
